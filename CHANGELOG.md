# Changelog

## v0.2 — unified working edition, November 2026

- Published the **37-page complete reading edition** as a single PDF with a unified cover and chapter sequence (Chapters 1–11).
- Added a finite-simplex Čencov proof, Fisher contraction under stochastic channels, divergence-induced dual connections, information projections, and geometric learning dynamics.
- Added a companion Python package, four notebooks, reproducible figures, and an automated regression-test suite.
- **Repository cleanup:** `book/` now contains only the current book PDF; editorial sources moved to `manuscript/`; reader-oriented README, contributor guidelines, and a mathematical-scope note added.

### Editorial limitations

- Chapters 1–5 were preserved from the original typeset PDF; their original editable LaTeX is not available.
- Code tests provide implementation checks, not formal verification of general theorems.
- A formal open-source license has not yet been selected.

## v0.1 — October 2026

- Original 27-page opening manuscript: four mathematical chapters, ten worked exercises, and a research roadmap.
